# Тексты Морского боя NMH

Это файл для редакторской правки. Под каждым ключом расположен текст, который увидит пользователь. Ключи и конструкции в фигурных скобках (`{name}`, `{count}`, `{cell}`) не меняйте: бот подставляет в них данные.

Бот читает этот файл напрямую. После сохранения правки новые сообщения сразу получат обновлённый текст — пересобирать приложение, править XML или запускать скрипты не нужно.

Новые записи добавляйте **в самом конце файла**, после раздела «Новые записи». Формат: заголовок `## новый_ключ`, пустая строка, затем текст. Новый ключ не создаст сам по себе кнопку или команду: для этого передайте файл разработчику, он добавит обработчик и начнёт использовать этот ключ в коде.
