# Рабочая супергруппа для команды NMH

Этот файл — короткая памятка для тех, кто работает с ботом каждый день.

## Первый запуск

1. Создайте супергруппу Telegram и включите в ней темы.
2. Добавьте бота администратором. Ему нужны права **отправлять сообщения**, **управлять темами** и **банить пользователей**.
3. Добавьте бота администратором в разрешённые приватные каналы сотрудников и укажите их полные ID в `ALLOWED_CHANNEL_IDS` файла `bot.properties` через запятую. Подписчики любого из этих каналов будут получать доступ к игре автоматически.
4. В `bot.properties` укажите токен, username и `ALLOWED_CHANNEL_IDS`.

```properties
BOT_TOKEN=токен_из_BotFather
BOT_USERNAME=username_бота_без_собаки
ALLOWED_CHANNEL_IDS=-1001234567890
```

5. Добавьте бота администратором в нужную супергруппу-форум. Затем её создатель, состоящий в одном из разрешённых каналов, отправляет в ней `/setup`. Только после этого бот создаст четыре темы:
   - **🛟 Заявки в игру** — новые пользователи и кнопки решения;
   - **📊 Выгрузки и статистика** — файлы CSV;
   - **📣 Рассылки** — сообщения для одобренных пользователей.
   - **📚 Команды и возможности** — полный список функций и инструкция по работе с ботом.

Создатель подключённой супергруппы получает права администратора автоматически. Ручные `ADMIN_IDS` не требуются.

Бот не доверяет другим каналам и группам: добавление его администратором в чужой чат не создаст темы, не выдаст права и не откроет статистику. Рабочий форум подключается только командой `/setup` от участника разрешённого канала.

## Администраторы

Откройте у бота команду `/admin` и нажмите **«Пригласить администратора»**. Бот пришлёт одноразовую ссылку. Передайте её человеку, которому хотите выдать права: после запуска бота по ссылке он сразу сможет модерировать заявки, скачивать выгрузки и делать рассылки.

Права хранятся в базе данных, поэтому после выдачи доступа перезапуск бота не требуется.

## Заявки

В теме «Заявки в игру» рядом с каждым человеком есть кнопки:

- **Одобрить** — открыть человеку доступ к боту;
- **Отклонить** — оставить доступ закрытым;
- **Заблокировать** — запретить пользоваться ботом и, если человек состоит в этой супергруппе, удалить его из неё.

## Выгрузки

В теме «Выгрузки и статистика» есть две кнопки:

- **Скачать статистику** — все известные пользователи, их Telegram ID, имя, username, статус доступа, актив, игры с компьютером, созданные и сыгранные игры с коллегами, победы и участие в турнире;
- **Заявки на турнир** — отдельный список предварительной регистрации.

То же можно написать прямо в рабочей супергруппе:

```text
/export_stats
/export_tournament
```

Команды и кнопки работают только для администраторов подключённой супергруппы и людей, получивших права по одноразовой ссылке.

## Рассылка

Перейдите в тему «Рассылки» и отправьте готовый текст обычным сообщением. Бот отправит его всем пользователям с одобренным доступом и сообщит, сколько получателей обработано. Перед отправкой проверьте текст: это действие выполняется сразу.

Чтобы бот получал такие сообщения из супергруппы, отключите **Privacy Mode** для него в BotFather: `/setprivacy` → выбрать бота → `Disable`.
