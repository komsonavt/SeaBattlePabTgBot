# Морской бой NMH Team

Telegram-бот с игрой «Морской бой», модерацией доступа, предварительной записью на турнир, таблицей лидеров, рассылками и CSV-выгрузками для команды.

Бот написан на Kotlin, работает через long polling и хранит данные в PostgreSQL. Docker использует заранее собранный JAR из `build/libs`, поэтому сервер не собирает Kotlin-проект.

## Что умеет бот

### Для игроков

- играть с компьютером без ограничения времени;
- играть с коллегой по персональной пригласительной ссылке;
- автоматически расставлять корабли;
- отсчитывать 3 минуты на ход в игре с коллегой: три пропуска разрешены, четвёртый означает техническое поражение;
- показывать своё поле, интерактивное поле соперника, счёт, пропуски, последнее событие и таймер;
- возвращаться к незавершённой игре с компьютером;
- смотреть топ-15 лидеров по PvP-играм;
- записываться на предварительный этап турнира и отменять запись.

### Для команды

- принимать заявки на доступ к игре: имя, фамилия и актив;
- автоматически открывать доступ сотрудникам, состоящим в приватном канале;
- одобрять, отклонять и блокировать пользователя;
- автоматически создать рабочие темы в супергруппе-форуме;
- отправлять рассылки всем пользователям с одобренным доступом;
- выгружать CSV со статистикой аудитории и заявками на турнир;
- хранить профили, статусы доступа, турнирную регистрацию и результаты игр в PostgreSQL.

## Команды игрока

Команды также показаны пользователю в меню Telegram рядом с полем ввода.

| Команда | Действие |
| --- | --- |
| `/start` | Запустить бота и открыть приветствие. Ссылка-приглашение на PvP передаётся этой же командой. |
| `/menu` | Открыть главное меню. |
| `/play_cpu` | Начать игру с компьютером. |
| `/play_friend` | Создать ссылку для игры с коллегой. |
| `/mygames` | Открыть актуальную карточку незавершённой игры. |
| `/leaderboard` | Посмотреть таблицу лидеров. |
| `/tournament` | Открыть предварительную запись на турнир. |
| `/surrender` | Предложить сдаться в активной партии. Потребуется подтверждение. |
| `/help` | Показать краткую подсказку. |

## Администрирование

Администраторы и ID рабочей супергруппы бот получает из Telegram и хранит в PostgreSQL. Вручную указывать их не нужно.

| Где использовать | Команда или действие | Результат |
| --- | --- | --- |
| Личный чат с ботом | `/admin` | Открывает панель с кнопками выгрузок. |
| Личный чат с ботом | Кнопка «Пригласить администратора» | Создаёт одноразовую ссылку: новый администратор получает права, открыв бота по ней. |
| Супергруппа модерации | `/export_stats` | Отправляет полный CSV в тему «Выгрузки и статистика». |
| Супергруппа модерации | `/export_tournament` | Отправляет CSV предварительной регистрации на турнир. |
| Тема «Заявки в игру» | Кнопки у заявки | Одобрить, отклонить или заблокировать человека. |
| Тема «Рассылки» | Обычное текстовое сообщение | Отправить сообщение всем одобренным пользователям. |

При блокировке бот закрывает доступ к игре. Если этот человек состоит в супергруппе модерации, бот также пытается удалить его из неё.

### Рабочие темы

При первом запуске бот создаёт и сохраняет в базе четыре темы:

1. `🛟 Заявки в игру` — новые заявки с кнопками решения.
2. `📊 Выгрузки и статистика` — кнопки для CSV и результаты выгрузок.
3. `📣 Рассылки` — место для текстов рассылок.
4. `📚 Команды и возможности` — обзор функций и прикреплённая полная инструкция из этого README.

ID тем хранятся в PostgreSQL. После перезапуска новые дубликаты не создаются.

## Статистика в CSV

Файл `nmh-audience-statistics.csv` содержит одну строку на известного пользователю бота человека:

- Telegram ID, имя, фамилию и username;
- текущий статус доступа, текст из заявки и актив;
- дату подачи и обработки заявки;
- число игр с компьютером;
- число созданных, сыгранных и завершённых PvP-игр, а также побед;
- наличие предварительной записи на турнир и дату записи;
- дату последнего обновления профиля.

CSV записывается в UTF-8 с BOM и безопасно экранирует значения, поэтому его можно открыть в Excel и Google Sheets.

## Настройка Telegram

1. Создайте супергруппу и включите в ней темы.
2. Добавьте бота администратором.
3. Выдайте ему права: **отправка сообщений**, **управление темами**, **блокировка пользователей**.
4. Добавьте того же бота администратором в разрешённые приватные каналы сотрудников и укажите их полные ID в `ALLOWED_CHANNEL_IDS` через запятую. Бот будет использовать для доступа только эти каналы.
5. В BotFather отключите Privacy Mode: `/setprivacy` → выбрать бота → `Disable`. Иначе бот не увидит сообщение, отправленное администратором в теме рассылок.
6. Добавьте бота администратором в нужную супергруппу-форум. Её создатель, состоящий хотя бы в одном разрешённом канале, должен отправить `/setup` в этой группе. Только тогда бот сохранит форум, создаст рабочие темы и загрузит список администраторов Telegram.

Пользователь, состоящий в подключённом приватном канале, получает доступ сразу. Если пользователь не состоит в канале или Telegram не может подтвердить подписку, бот предложит отправить заявку модератору.

Добавление бота в любой другой канал или супергруппу не даёт этому чату прав: бот игнорирует его и не создаёт темы, не назначает администраторов и не отправляет выгрузки.

Фотографию бота Telegram не позволяет менять через Bot API. Готовый файл лежит в [assets/bot-avatar.png](assets/bot-avatar.png); в BotFather используйте `/setuserpic`, выберите бота и отправьте этот файл.

## Конфигурация

### `bot.properties`

Создайте файл из [bot.properties.example](bot.properties.example). Он не попадает в Git и подходит для секретов.

```properties
BOT_TOKEN=123456:token_от_BotFather
BOT_USERNAME=имя_бота_без_собаки

TOURNAMENT_DATE=20 сентября
TOURNAMENT_PRIZES=Победителя и призёров ждут призы.
TOURNAMENT_BRACKET_ENABLED=false
```

| Параметр | Обязателен | Назначение |
| --- | --- | --- |
| `BOT_TOKEN` | Да | Токен от BotFather. Никому его не отправляйте. |
| `BOT_USERNAME` | Да | Username бота без `@`; нужен для ссылок-приглашений. |
| `TOURNAMENT_DATE` | Нет | Текст даты предварительного старта. |
| `TOURNAMENT_PRIZES` | Нет | Текст о призах. |
| `TOURNAMENT_BRACKET_ENABLED` | Нет | `false` для MVP; автоматический запуск сетки выключен. |
| `GROUP_SIZE` | Нет | Размер турнирной группы, по умолчанию `4`. |
| `PLAYERS_PER_GROUP_ADVANCE` | Нет | Сколько игроков выходит из группы, по умолчанию `2`. |

Параметры PostgreSQL в `bot.properties` нужны только при запуске без Docker: `DB_URL`, `DB_USER`, `DB_PASSWORD`.

### `.env`

Создайте `.env` из [.env.example](.env.example). Здесь находятся настройки Docker и пути к внешним файлам:

| Параметр | Назначение |
| --- | --- |
| `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` | База данных Docker. Обязательно поменяйте пароль. |
| `BOT_CONFIG_HOST_FILE` | Путь к `bot.properties`, обычно `./bot.properties`. |
| `COPY_HOST_FILE` | Путь к редактируемым текстам, обычно `./seaBattleBot_text_for_editor.md`. |
| `EMOJI_HOST_FILE` | Путь к [emoji.xml](emoji.xml) с эмодзи поля. |
| `BOT_TOKEN`, `BOT_USERNAME` | Необязательное переопределение одноимённых значений из `bot.properties`. Непустое значение `.env` имеет приоритет. |

Не задавайте в `.env` старый путь `COPY_HOST_FILE=./copy.xml`: тексты теперь читаются прямо из Markdown.

### Тексты и эмодзи

- [seaBattleBot_text_for_editor.md](seaBattleBot_text_for_editor.md) — все пользовательские тексты. Бот читает Markdown напрямую; после сохранения файла новые сообщения используют обновлённые значения без пересборки.
- [emoji.xml](emoji.xml) — внешний набор эмодзи с ключами `sea`, `ship`, `miss`, `hit`, `sunk`. В нём уже настроены тестовые custom emoji NMH; перед продакшеном достаточно заменить значения `id` на новые Telegram `custom_emoji_id`.

Ключи `## ...` и конструкции вроде `{name}` в текстовом Markdown менять нельзя: их использует код.

## Установка на сервере

Проект разворачивается в `/opt/SeaBattlePabTgBot`.

```bash
cd /opt/SeaBattlePabTgBot
git pull --ff-only
docker compose up -d --build
docker compose logs --tail=100 -f bot
```

Последняя команда обязательна: она показывает успешный старт или конкретную причину ошибки конфигурации.

При обычной правке `seaBattleBot_text_for_editor.md` пересобирать контейнер не требуется. При изменении `emoji.xml` выполните:

```bash
docker compose restart bot
docker compose logs --tail=100 -f bot
```

## Локальная сборка

Соберите JAR на рабочем компьютере, затем закоммитьте обновлённый `build/libs/SeaBattlePabTgBot-1.0.0.jar`:

```powershell
.\gradlew.bat test
.\gradlew.bat jar
```

## Проверки

Перед передачей изменений запускайте тесты. Они проверяют игровую механику, игровые кнопки, таймауты, обработку API и экранирование CSV. После развёртывания дополнительно проведите реальные проверки: отправьте заявку, одобрите её, сыграйте с компьютером и коллегой, скачайте оба CSV и протестируйте рассылку на тестовом пользователе.
